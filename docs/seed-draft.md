# IT-Index シード下書き（作業用）

基本情報テキストの巻末索引（ページ590〜606）を元に、`public/seed/terms.json` の下書きを作る作業ファイル。
正本の形式は [seed-format.md](./seed-format.md)。**この doc はレビュー用の中間物**で、確定後にJSON化する。

## 注意
- `summary` / `readings` は**私（AI）の一般知識による下書き**。試験的な正しさの判断は本人が行う（seed-format §7）。
- `field` は語義とシラバスからの**推定**。自信の低いものは `？`。確定は本人（§7 step1）。
- **除外候補は削除ではなくタグ付け**。JSONには入れないが、この doc に理由付きで残す。

## field について（重要）
- 本人指示により **`AI` 分野を新設**（seed-format §5 の23分類＋`AI`＝計24）。
  - ⚠️ **正本 [seed-format.md §5](./seed-format.md) の一覧にも `AI` を追記する必要あり**（アプリの検証がこの一覧を使うため）。§5への追記は別途確認のうえ行う。
- **field 判定ルール（当たりを付けるための方針。要レビュー）**
  - プログラム/マークアップ/問合せ言語（C, COBOL, CSS, DTD 等）→ `アルゴリズムとプログラミング`
  - Web の仕組み・プロトコル（cookie, CGI, DNS, HTTP 等）→ `ネットワーク`
  - 暗号・攻撃・認証 → `セキュリティ`
  - CxO・経営組織・財務・CSR → `企業活動`
  - マーケ・経営フレームワーク（3C, CRM, BSC 等）→ `経営戦略マネジメント`
  - 生産/エンジニアリング系（CAD/CAM/CAE, CIM 等）→ `ビジネスインダストリ`
  - EVM・見積り・PMBOK（AC, BAC, CPI, CPM 等）→ `プロジェクトマネジメント`
  - ITIL・SLA・構成管理（CMDB 等）→ `サービスマネジメント`
  - 監査・内部統制（COBIT, COSO 等）→ `システム監査`
  - 標準化団体・法規・知財（ANSI, ISO, JIS 等）→ `法務`
  - CPU/メモリ/レジスタ/DMA → `コンピュータ構成要素`／記憶媒体・周辺機器 → `ハードウェア`／OS・ミドル・ファーム → `ソフトウェア`
  - AI・機械学習（AI, CNN, ChatGPT 等）→ `AI`

## 凡例
- `？` … 判定に自信が低い／要確認（語義が不明確、または分野が大きく割れるもの）。
