# マルチメディア — 参考情報（fe-siken.com主軸）

出典: fe-siken.com カテゴリ8（情報メディア）8-1（マルチメディア技術, 35語）・8-2（マルチメディア応用, 24語）。突き合わせは terms.json 用語リスト（68語、ファイル記載順）に対して行った。fe-sikenでは分野名が「情報メディア」だが、terms.jsonでは「マルチメディア」に対応する。数字の全角/半角・漢数字（例:「3」と「三」）の表記ゆれは記号の表記ゆれに準じて同一語とみなした。長音符号（ー）の有無も表記ゆれとして吸収した。

- **3次元映像**: 立体的な映像表現を指し、視覚に奥行きを感じさせる技術である。視聴者の目に2つの異なる画像を提供することで実現される。
- **AR**: 拡張現実の略で、現実の世界にコンピュータで生成された情報や画像を重ねて表示する技術である。
- **BMP**: 主に静止画を保存するための画像ファイル形式の一つである。画像をピクセル単位で表現するため、高品質な画像データを保持することができる。
- **CG**: コンピュータを用いて生成される画像やアニメーションを指す。2D（平面）グラフィックスと3D（立体）グラフィックスが含まれる。
- **Exif**: 静止画ファイルのメタデータを格納するためのフォーマットである。デジタルカメラやスマートフォンで撮影した画像に、撮影日時、カメラの設定、地理的位置情報（GPS座標）などを自動的に付加する役割を果たす。
- **GIF**: 特に静止画や簡単なアニメーションを表示するための画像フォーマットである。256色までのカラーパレットを使用し、色数が限られているためファイルサイズが比較的小さい。
- **JPEG**: 静止画像の圧縮フォーマットの一つで、特に写真やデジタル画像の保存に広く使われている。データの一部を取り除く「lossy compression」と呼ばれる手法を用いる。
- **MIDI**: 電子楽器やコンピュータが音楽データをやり取りするための規格である。楽器が演奏するノートや強さ、音色といった情報をデジタルデータとして送受信する。
- **MMR**: 情報の圧縮や伸張に関連する技術的な手法の一つである。データのサイズを小さくするための方法で、特に映像や音声データの圧縮に役立つ。
- **MP3**: 音声データの圧縮形式の一つであり、特に音楽や音声ファイルの保存や配信に広く使用されている。オーディオデータを効率的に圧縮し、ファイルサイズを大幅に減少させつつ音質を保つ。
- **MPEG**: 動画や音声データを圧縮し、効率よく伝送するための規格群である。主に動画ファイルの圧縮や再生に使用される。
- **MR**: 現実世界と仮想世界を融合させた技術を指す（複合現実）。現実の環境に仮想のオブジェクトを重ねて表示できることで、よりインタラクティブな体験を提供する。
- **PNG**: 静止画を扱うためのファイル形式である。画質を保ちながらデータサイズを小さくする特性があり、背景を透明にできるためロゴやアイコンなどに適している。
- **TIFF**: 高品質な静止画を保存するためのフォーマットである。主に印刷業界や写真業界で使用され、多様な色深度や圧縮形式をサポートしている。
- **VR**: 仮想現実の略で、コンピュータによって生成された3D空間にユーザーが没入し、実際にその中にいるかのような体験を提供する技術である。
- **色の三原色**（fe-siken表記「色の3原色」）: 他のすべての色を組み合わせて生成するための基本的な色のことを指す。通常、赤、緑、青の三色が代表的な例。
- **コンテナフォーマット**: 複数のメディアデータを一つのファイル内にまとめて格納する形式である。音声や動画、字幕など異なるデータを効率的に管理するために使用される。
- **コントラスト**: 色や明るさの違いを指し、視覚的な明瞭さや鮮明さを生み出す要素である。
- **ストリーミング**: 音声や映像をインターネットを通じてリアルタイムで再生する技術である。ユーザーはデータをすべてダウンロードせずに、すぐにコンテンツを楽しむことができる。
- **バーチャルサラウンド**: 音響技術の一つで、少ないスピーカーやヘッドフォンを使用して、立体的な音場を再現する技術である。
- **光の三原色**（fe-siken表記「光の3原色」）: 赤（Red）、緑（Green）、青（Blue）の三色を基にした色の表現方法である。これらの色を組み合わせることによって、様々な色を作り出すことができる。
- **ビデオオンデマンド**: 視聴者が自分の好きなタイミングで動画を視聴できるサービスのことである。従来の放送時間に縛られることがない。
- **メタバース**: 仮想空間と現実世界を融合させたデジタル環境を指す。この空間では、ユーザーはアバターとして参加し、交流やゲームが可能である。
- **モーションキャプチャ**（fe-siken表記「モーションキャプチャー」）: 人間や動物の動きをデジタルデータとして記録する技術である。映画やゲーム制作において、リアルな動きを再現するために広く利用されている。
