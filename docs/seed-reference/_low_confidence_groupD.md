# グループD（システム開発技術／ソフトウェア開発管理技術／プロジェクトマネジメント）低確信度リスト

3分野のsummary下書き作成時に、参考情報（fe-siken/e-words）に該当ページがなく、かつ一般知識のみで書くことに確信が持てなかった語を列挙する。**内容自体は「事実と異なることを書かない」方針で薄めに書いてあるが、本人によるレビューを特に推奨する。**

## システム開発技術

- **合成コード**: fe-siken・e-wordsいずれにも該当ページなし。「区分コードや桁別コードなど複数のコード化方式を組み合わせたコード」という一般的なコード設計の分類知識で書いたが、この定義が本語の試験上の正確な定義と一致するか確信が持てない。
- **誘導可能性**: 情報源なし。ISO/IEC 25010等の使用性（ユーザビリティ）関連の標準的なサブ特性名として明確に一致するものを確認できなかった。「利用者を想定した操作へ導きやすい度合い」という推測で書いたが、試験用語としての正確な定義に自信が持てない。

## ソフトウェア開発管理技術

- **SCI**: fe-siken・e-wordsいずれにも該当ページなし。`_flags.md`でも「略語の候補が複数考えられ紛らわしい」と指摘されている。「ソフトウェア構成品目（Software Configuration Item）」という一般的な構成管理用語として書いたが、他の意味（例: Selective Chemical Inhibitor等、無関係の略語）と混同していないか確信が持てない。

## プロジェクトマネジメント

- **標準タスク法**: fe-siken・e-wordsいずれにも該当ページなし。「標準的な作業単位ごとの所要時間を積み上げて工数を見積もる手法」という、用語名からの推測で書いた。ソフトウェア開発の工数見積り手法の一種として一般に説明される内容だが、試験で問われる定義と細部が一致するか確信が持てない。

## 備考

- 上記以外の「情報源なし」の語（結合点時刻、最早/最遅結合点時刻、ユーザーファンクションタイプ、トレンドチャート、補正係数、テクニカルプロセス、システムライフサイクル等）は、周辺語（結合点・最早開始時刻・COCOMO等）から一般的なIT知識で十分に確信を持って書けたため、このリストには含めていない。
- ラグ／リードは`_flags.md`の指摘どおり、fe-siken側の同音異義語の説明（ネットワーク遅延／営業見込み客）を採用せず、PMBOKのスケジュール用語（後続作業を遅らせる猶予期間／前倒しできる期間）で書いた。
