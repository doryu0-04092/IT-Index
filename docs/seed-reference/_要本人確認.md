## この文書について

`docs/seed-reference/` 配下の4分野（基礎理論／アルゴリズムとプログラミング／コンピュータ構成要素／システム構成要素）で「未収録」（情報源なし）だった語を、以下の3種類に分類した：

1. **同義語・重複カウント** — 各ファイル内で別見出しとして既に説明があるため、対象ファイルに直接「→ 用語Xと同義」等の注記を追記済み（この一覧には含めない）
2. **標準語（本ファイルの対象）** — 一般的なIT用語・数学/統計の基礎概念で、AIの一般知識で十分正確に説明できると判断した語。**そのまま「未収録」表記を維持**しており、各ファイル本体は変更していない
3. **要注意語** — 試験特有の規定・紛らわしい語・ニッチな専門用語。e-words.jpで確認済み、または確認できず「要本人確認」と対象ファイルに注記済み（この一覧には含めない）

以下は分類2の語を分野ごとに列挙したもの。件数が多いため、同じ理由でまとめられる語はグループ化して一言の理由を添えている。**「本当にAI一般知識で足りるか」は本人の判断を優先するので、違うと思う語があればここで指摘してほしい。**

## この文書について

`ネットワーク.md` と `セキュリティ.md` の「情報源なし」語について、以下の順で仕分けを行った。

1. **分類1（同義語・重複）**: 同じファイル内の別見出しに既に説明がある語 → 該当行に「→ ○○と同義」を追記済み
2. **分類3（要注意語・e-words確認済み）**: 試験特有の細かい規定・紛らわしい語・組織固有名等、本当に危ないと判断した語 → e-words.jpで裏取りし、該当行に確認結果を追記済み（一部、e-wordsにも掲載がなかった語は「要本人確認」のまま）
3. **分類2（本一覧）**: 上記のどちらにも当てはまらなかった残りの語。**AIの一般知識で対応できる標準的な語と判断**し、`情報源なし` の記載はそのまま維持した。念のため一覧化するので、違うと思うものがあればすぐ指摘してほしい。

各語について、なぜ「一般知識で対応可能」と判断したかを、似た語をまとめてグループ単位で理由付けしている（個々に一言ずつ書くと冗長になるため）。
