# ヒューマンインタフェース — 参考情報（fe-siken.com主軸）

出典: fe-siken.com カテゴリ7（ユーザーインタフェース）7-1（ユーザーインタフェース技術, 36語）・7-2（UX/UIデザイン, 39語）。突き合わせは terms.json 用語リスト（56語、ファイル記載順）に対して行った。fe-sikenでは分野名が「ユーザーインタフェース」だが、terms.jsonでは「ヒューマンインタフェース」に対応する。

- **JIS X 8341**: Webコンテンツのユニバーサルデザインに関する日本の規格である。
- **JIS Z 8530**: 人間中心設計に関する日本の規格であり、製品やサービスを利用する人々の視点から設計することを重視するものである。
- **NUI**: 自然なユーザーインタフェースの意味で、ユーザーが直感的に操作できるインタフェースである。
- **UXデザイン**: ユーザーが製品やサービスを使用する際の体験を設計するプロセスであり、製品やサービスがどれほど使いやすいか、魅力的か、ユーザーにとって有益かを考慮し、最適化することを目的とする。
- **UXライティング**: ユーザーエクスペリエンス（UX）を向上させるための文章作成技術である。
- **VUI**: 音声を用いてユーザーと機械が相互作用する仕組みである。
- **WAI**: Webアクセシビリティイニシアティブの略であり、インターネット上の情報をすべての人々が利用できるようにするための取り組みである。
- **WCAG**: Webコンテンツのアクセシビリティ向上を目指す指針である。
- **アクセシビリティ**: すべての人が情報や機能にアクセスできるように設計することを指す。
- **アコーディオン**: グラフィカルユーザーインターフェースにおいて、情報を折りたたみ式で表示するためのコンポーネントである。
- **カルーセル**: Webデザインにおいて、画像や内容をスライド形式で表示するための要素である。
- **ジェスチャーインタフェース**: ユーザーが手や指の動きを使ってデバイスを操作するためのインターフェースである。
- **自然言語インタフェース**: ユーザーが日常的な言葉を用いてコンピュータやソフトウェアと対話できる仕組みである。
- **チェックボックス**: ユーザーが複数の選択肢から一つまたは複数を選ぶためのインターフェース要素である。
- **チャンク**: 情報をグループ化して扱うことで、記憶や理解を助ける方法であり、膨大な情報を小さくまとまった単位に分ける。
- **ツールチップ**: グラフィカルユーザーインターフェースにおいて、特定のアイコンやボタンにマウスカーソルをかざした際に表示される小さな情報ウィンドウである。
- **テキストボックス**: グラフィカルユーザーインターフェースにおいて、ユーザーが文字を入力するための領域である。
- **デザインの原則**: 視覚的な情報を効果的に伝えるための基本的なガイドラインとなる近接、整列、反復、対比の4つの要素である。
- **トグルボタン**: グラフィカルユーザーインターフェースにおいて、選択や設定をONまたはOFFと切り替えるためのボタンである。
- **ナビゲーション**: 情報アーキテクチャにおいて、ユーザーが情報を探しやすくするための仕組みを指す（7-2ではWebサイトやアプリケーションにおいて、ユーザーがコンテンツを効率的に見つけることを可能にするための仕組み、とも説明）。
- **ノンバーバルインタフェース**: 言葉を使わずにユーザーとシステムがコミュニケーションを行うためのインターフェースである。
- **ヒューリスティック評価**: ユーザビリティ評価の手法の一つであり、専門家が特定の原則やガイドラインに基づいてユーザーインターフェースを評価し、使いやすさの問題を特定するために使用される。
- **ポップアップメニュー**: ユーザーインターフェースの一部として表示される、選択肢を提供する小さなメニューである。
- **ホバー**: グラフィカルユーザーインターフェースにおいて、マウスポインタが特定の要素の上に置かれたときに発生する視覚的な効果である。
- **マルチタッチインタフェース**: ユーザーが複数の指を使って同時に操作できるインターフェースである。
- **ユーザビリティ**: 製品やシステムがユーザーにとって使いやすい程度を示す指標である。
- **ユーザビリティテスト**: 製品やサービスがどれだけ使いやすいかを評価するための手法である。
- **ラジオボタン**: ユーザーが複数の選択肢の中から1つだけを選ぶことを可能にするGUI要素である。
- **リストボックス**: ユーザーが選択肢から1つ以上の項目を選ぶことができるGUIのコンポーネントである。
