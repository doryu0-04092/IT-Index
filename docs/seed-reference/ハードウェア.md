# ハードウェア — 参考情報（fe-siken.com主軸）

出典: fe-siken.com カテゴリ6（ハードウェア）6-1（全22語）。突き合わせは terms.json 用語リスト（138語、ファイル記載順）に対して行った。

**重要な注記**: fe-siken.comのカテゴリ6「ハードウェア」は、シラバス上「論理回路・制御理論」（AND/OR/NOT回路、フリップフロップ、フィードバック制御、ダイオード・トランジスタ・IC/LSI/VLSI/FPGAなど）のみを扱っており、terms.jsonのハードウェア分野が扱う「周辺機器・記憶装置・入出力インタフェース」（プリンター、HDD、USB、センサー類など）とはほぼ重複しない。そのため fe-siken からの直接一致はごくわずかで、大半の語は「見つからなかった語」に分類される。この分野食い違いは `_flags_groupB.md` にも記載した。

- **PWM制御**: デジタル信号を用いてアナログ信号の強さを制御するパルス幅変調の技術である。一定の時間における信号の「オン」と「オフ」の時間の比率を調整することにより、出力を変化させる。
- **オープンループ制御**: 出力の状態をフィードバックしない制御方式である。入力信号と制御アルゴリズムに基づいて出力が決定されるが、出力の結果に応じて制御を修正したり調整したりしない。
- **クローズドループ制御**: 制御システムの一種で、出力情報をフィードバックし、それに基づいて制御入力を調整する方式である。目標値と実際の出力値を比較し、その差を元に制御を行うことにより、より正確な制御を実現する。
- **シーケンス制御**: 機械や装置の動作を順序立てて管理する手法である。特定の条件に基づいて機器を段階的に動かすためのもので、プロセスの効率化や安定性を高める。
- **フィードバック制御**: システムの出力を監視し、それに基づいて入力を調整する制御方式である。この方法により、目標とする値に出力を近づけることが可能になる。
- **BSDL**: fe-sikenのカテゴリ5-5（オープンソースソフトウェア分野）に、terms.jsonのハードウェア分野が指す意味（Boundary Scan Description Language＝集積回路の境界走査テスト記述言語）と一致する説明が掲載されている："集積回路のテストやデバッグに使用される言語である。電子回路の端子や接続状態を記述し、ハードウェアの正常動作を確認する手段として重要。" ただしfe-siken側はこの語を「BSD License」の略と誤認したか、見出し配置を誤った可能性がある（`_flags_groupB.md` 参照）。
- **ICE**: fe-sikenのカテゴリ5-4（開発ツール分野）に一致する説明が掲載されている："組込みシステムの開発において、ハードウェアの動作を模倣するためのツールである。実際の基板上に接続され、マイクロコントローラやマイクロプロセッサの動作をエミュレーションすることで、プログラムのデバッグを行うことが可能である。" fe-sikenは開発ツール（ソフトウェア）分野に分類しているが、terms.jsonはハードウェア分野に置いている（`_flags_groupB.md` 参照）。
