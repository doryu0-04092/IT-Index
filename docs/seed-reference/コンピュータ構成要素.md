# コンピュータ構成要素 — 参考情報（fe-siken.com主軸）

- **3入力多数決回路**: 未収録（e-wordsにも掲載なし。要本人確認）
- **5大装置**: 未収録（「コンピュータの五大装置」表記でfe-sikenにあり：演算装置、制御装置、記憶装置、入力装置、出力装置の五つの基本部品）
- **A/D変換**: fe-siken: アナログ信号をデジタル信号に変換するプロセスである。アナログ信号を一定の時間間隔でサンプリングし、それに基づいてデジタル値を生成する
- **AND回路**: fe-siken: すべての入力が「真」のときのみ出力が「真」となる論理回路である
- **CISC**: fe-siken: 複雑な命令セットを持つコンピュータアーキテクチャである ／ 補足（marke-predict）: 複雑な命令セットを持つ従来型コンピューターアーキテクチャ
- **CPU**: fe-siken: コンピュータの主要な演算処理を行う部品である。「プロセッサ」とも呼ばれる
- **CPU内部バス**: fe-siken（「内部バス」表記、一般概念として）: コンピュータ内部のさまざまな部品、特にCPUやメモリ、周辺機器などがデータをやり取りするための通信路である
- **D/A変換**: fe-siken: デジタル信号をアナログ信号に変換するプロセスである
- **DDR SDRAM**: 未収録（「RAM」「DRAM」の一般説明のみ）
- **DIMM**: fe-siken: メモリの一種で、主にパソコンやサーバで使用される。二列の接続端子を持ち、各端子は異なる信号をやり取りする
- **DMAコントローラ**: 未収録（「DMA方式」参照）
- **DMA転送**: 未収録（「DMA方式」参照）
- **DMA方式**: fe-siken: コンピュータがデータを入出力デバイスとメモリの間で直接転送する方式を指す。CPUはデータ転送を行うための時間を省略でき、他の処理を同時に行うことが可能になる
- **DRAM**: fe-siken: コンピュータの主記憶装置の一つであり、データを一時的に保存するために使用される。電気的に情報を保持するが、一定の時間が経つと内容が消えてしまうため、定期的にそのデータを再書き込みする必要がある ／ 補足（marke-predict）: コンデンサにより情報を記憶し低速・高集積・大容量・消費電力小の特徴がある
- **DSP**: 未収録
- **Dynamic RAM**: 情報源なし（→ DRAMと同義。DRAMの説明を参照）
- **EEPROM**: 未収録（fe-sikenの「ROM」は読み出し専用の一般説明のみで、電気的に書換え可能なEEPROMの特性とは矛盾するため転用不可）
- **EOR回路**: 未収録（fe-sikenの「OR回路」は論理和回路でありEOR＝排他的論理和回路とは別物のため不採用）
- **EPROM**: 未収録（EEPROMと同様の理由で「ROM」からの転用は不採用）
- **FLOPS**: fe-siken: 1秒間に処理できる浮動小数点演算の回数を表す単位である
- **FPGA**: 未収録 ／ 補足（marke-predict）: プログラミング可能なLSI
- **FPU**: 未収録
- **GHz**: 未収録
- **GR**: 未収録（e-wordsにも掲載なし。要本人確認）
- **I/Oバス**: fe-siken（「バス」表記、一般概念として）: コンピュータ内部でデータをやり取りするための伝送路である
- **IAR**: 情報源なし（→ 命令アドレスレジスタと同義。命令アドレスレジスタの説明を参照）
- **IC**: 未収録（「集積回路」参照）
- **MHz**: 未収録
- **MIMD**: fe-siken: 複数の命令を同時に処理し、異なるデータを扱う方式である
- **MIPS**: fe-siken: 1秒間に処理できる命令の数を示すプロセッサの性能指標である
- **MISD**: fe-siken: 複数の命令ストリームが一つのデータストリームに基づいて動作するアーキテクチャである
- **NAND回路**: fe-siken: ANDゲートの出力を反転させた論理ゲートである
- **NFP**: 未収録（e-wordsにも掲載なし。要本人確認）
- **NOR回路**: 未収録（fe-sikenの「OR回路」は論理和回路でありNOR＝否定論理和回路とは別物のため不採用）
- **NOT回路**: fe-siken: 入力信号の値を反転させる論理回路である
- **OR回路**: fe-siken: 入力信号のいずれかが「真」となる場合に出力が「真」となる回路である
- **PCIバス**: fe-siken（「バス」表記、一般概念として。PCI規格自体の説明はfe-sikenにあり：コンピュータの内部で周辺機器を接続するためのバス規格の一つ）
- **PROM**: 補足（marke-predict）: 電気的にデータの書き換えや消去が可能で安価で高集積化が可能（fe-sikenの「ROM」一般説明とは矛盾する点に注意 — `_flags_groupA.md`参照）
- **PSW**: 未収録（e-wordsにも掲載なし。要本人確認）
- **RAM**: fe-siken: コンピュータの記憶装置であり、データを一時的に保存する役割を持つ。主にプログラムの実行やデータ処理の際に使用され、必要な情報に素早くアクセスできる特徴がある。揮発性であるため、電源が切れるとデータは消失する
- **RISC**: fe-siken: 命令セットを簡素化することを目的とするプロセッサアーキテクチャである ／ 補足（marke-predict）: 複雑化した命令を単純化して処理速度を高速にするアーキテクチャ
- **ROM**: fe-siken: 読み出し専用の記憶装置を意味する。データを書き込むことはできず、主にコンピュータの基本的なソフトウェアやハードウェアの情報を保存する役割を果たす。不揮発性で、電源を切っても消えない
- **SDRAM**: fe-siken（「RAM」表記、一般概念として）
- **SIMD**: fe-siken: 一つの命令で複数のデータを同時に処理する技術である
- **SISD**: fe-siken: 単一の命令が単一のデータを処理するシステムである
- **SO-DIMM**: fe-siken: コンピュータのメモリモジュールの一種で、小型のDIM（Dual In-line Memory Module）である。通常、ノートパソコンや小型デバイスで使用されることが多い
- **SP**: 情報源なし（→ スタックポインタと同義。スタックポインタの説明を参照）
- **SPEC**: 未収録（SPECint/SPECfpの個別説明のみ） → e-wordsで確認: "コンピュータシステムを実際の使用環境に近い状態で性能測定する標準的な手法を策定し、測定結果を登録・公表する国際的な非営利団体。1988年設立"
- **SPECfp**: 未収録
- **SPECint**: 未収録
- **SRAM**: fe-siken: データを一時的に記憶するためのメモリの一種で、特に高速なアクセスが可能である。トランジスタを使用し、電源が供給されている限り情報を保持する。CPU内部のキャッシュメモリとして利用される ／ 補足（marke-predict）: フリップフロップ回路で情報を記憶し高速・低集積・小容量・消費電力大の特徴がある
- **Static RAM**: 情報源なし（→ SRAMと同義。SRAMの説明を参照）
- **TPC**: 未収録 → e-wordsで確認: "コンピュータシステムの性能評価の方法や基準などを策定する業界団体の一つ。データベースシステムなど企業の情報システムで用いる性能指標の策定を行っている"
- **VLIW**: fe-siken: 一つの命令の中に複数の操作がまとめられるアーキテクチャである
- **VRAM**: fe-siken（「RAM」表記、一般概念として）

- **アドレスバス**: fe-siken: コンピュータの内部でデータの送受信先を指定するための信号線の集合である。メモリやその他のデバイスの位置情報を伝える役割を担う
