# 法務 — 参考情報（fe-siken.com主軸）

出典ページ: fe-siken.com/keyword/23/23-1/（知的財産権）, 23-2（セキュリティ関連法規）, 23-3（労働関連・取引関連法規）, 23-4（その他の法律・ガイドライン・技術者倫理）, 23-5（標準化関連）, 一部21-1（ビジネスシステム）

- **ANSI**: 米国における標準化団体であり、さまざまな製品やサービスの標準を制定する役割を果たしている。
- **EU一般データ保護規則**: fe-sikenでは「一般データ保護規則」として説明：個人情報の保護を目的とした欧州連合（EU）の法律。GDPRとも呼ばれ、個人データの収集・使用・保存・破棄に関する厳格なルールを定める。
- **GDPR**: 上記「一般データ保護規則」と同一の項目（略称）。
- **GPL**: fe-sikenに見つからず（LGPLは掲載あり）。
- **IEC**: 電気・電子・関連技術の国際規格を策定する組織。
- **IEEE**: 電気・電子に関する技術の発展を促進するための国際的な学会。Wi-FiやBluetoothなどの規格もIEEEが制定した標準に基づく。
- **ISO**: 国際的に通用する標準を策定するための組織。ISO9001（品質管理）など、さまざまな分野で標準を確立する。
- **ISO14000シリーズ**: fe-sikenでは「ISO 14000」として説明：環境マネジメントのための国際的な標準規格群。ISO 14001が環境マネジメントシステムの要件を示す。
- **JIS**: 日本の産業における標準規格。製品やサービスの品質、安全性、互換性を確保することを目的とする。
- **JIS Q 14001**: 環境マネジメントシステムに関する国際規格。組織が環境に対する影響を管理・改善するためのフレームワークを提供する。
- **JIS Q 15001**: 個人情報の保護に関する日本の標準規格。個人情報の収集、利用、保管、提供に関するルールを定めている。
