# グループC（ネットワーク・セキュリティ）低確信度の語

`summary`は作成済みだが、内容の確信度が他の語より低いもの。理由付きで列挙する。

## ネットワーク

- **キャリア**: 参照情報(ネットワーク.md)の記述が「キャリアアグリゲーション」の説明と同一になっており、fe-siken側の取り違えの可能性がある。「搬送波」という意味と「移動体通信事業者(通信キャリア)」という意味の両方があり得るが、`搬送波`が別途独立した語として存在するため、本エントリは「移動体通信事業者の通称」の意味で記述した。試験文脈でどちらを指すか未確認。

## セキュリティ

- **KMS**: `_flags.md`で指摘の通り、e-words上の主見出しは「キー管理サービス」(Microsoft製品のライセンス認証の仕組み)だが、一般的な「暗号鍵管理システム」の意味で使われる場合もあり、文脈により指す内容が異なる。本エントリは後者(汎用的な鍵管理の仕組み)として記述したが、試験の意図と一致するか未確認。
- **JIS X 3060**: 参照情報(セキュリティ.md)でも「情報源なし。e-wordsにも掲載なし。要本人確認」と明記されたまま未解決だった語。安全側に振り、規格の一般的な位置づけ(情報セキュリティ関連の規格番号)のみを記述し、具体的な内容の断定は避けた。
- **IDF**: ネットワーク用語(中間配線盤)としての一般知識で記述したが、この語が`field: セキュリティ`に分類されている理由・出題意図とは一致しない可能性がある(内容自体の正確性は高いが、この分野で問われる文脈が不明)。

上記4語は、他の語と比べて「参照情報と一般知識の整合性」または「出題意図との一致」に不確実性が残る。本人によるレビュー時に優先的に確認すること。
