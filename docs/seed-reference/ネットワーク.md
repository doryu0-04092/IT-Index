# ネットワーク — 参考情報（fe-siken.com主軸）

- **100BASE-T**: 100メガビット毎秒の通信速度を持つイーサネット規格の一つである。この規格は、主にツイストペアケーブルを使用して、データを送受信するために設計されている。通信距離が最大100メートルで、接続するデバイスが多くのオフィス環境や家庭内ネットワークで広く使用されている。
- **100BASE-TX**: 100メガビット毎秒の通信速度を持つイーサネット規格の一つである。この規格は、主にツイストペアケーブルを使用して、データを送受信するために設計されている。通信距離が最大100メートルで、接続するデバイスが多くのオフィス環境や家庭内ネットワークで広く使用されている。
- **10GBASE-T**: 10ギガビットEthernetの規格であり、LANにおいて、高速データ通信を実現する方法である。この規格は、ツイストペアケーブルを使用して最大100メートルの距離でデータを送受信することができるため、既存のネットワークインフラを活用できる利点がある。
- **5G**: モバイル通信の第5世代で、これまでの通信技術に比べて高速で低遅延なデータ通信を実現し、自動運転車やIoTデバイスの連携を強化する。
- **CGI**: Webサーバと外部プログラムとのインターフェースを定義する規則であり、クライアントリクエストを受け取り、データベースアクセスや計算を行い、その結果をWebページとして返す。
- **CIDR**: IPアドレスの割り当てとルーティングを効率的に行うための手法である。従来のIPアドレス割り当ては、クラスA、B、Cといった固定のクラスに基づいていたが、CIDRでは、ネットワークのサイズに応じて柔軟にアドレス空間を分配することができる。
- **cookie**: Webサイトがユーザーのブラウザに保存する小さなデータファイルで、訪問履歴やログイン情報を記録し、次回訪問時に自動的に引き出すことができる。
- **CSMA/CD**: コンピュータネットワークのメディアアクセス制御方式の一つである。この方式は、複数の端末が同じ通信路を共有する場合に、どのようにデータを送信するかを管理するために使われる。／ 補足(marke-predict): イーサネットなどのバス型LANで使用される通信回線制御方式
- **DHCP**: ネットワークに接続されるデバイスに自動的にIPアドレスやその他の設定情報を割り当てるためのプロトコルである。これにより、手動での設定作業を省略でき、特に大規模なネットワークでは管理が容易になる。／ 補足(marke-predict): ネットワーク上の機器にIPアドレスを自動的に割り当てるためのプロトコル
- **dig**: DNS（ドメインネームシステム）に関する情報を取得するためのツールである。主に、Webサイトのドメイン名からIPアドレスを調べたり、ドメインの登録情報を表示したりする際に用いられる。
- **DNS**: 人が覚えやすいドメイン名を機器が理解できるIPアドレスに変換する仕組みである。 / インターネットやネットワーク上のホスト名をIPアドレスに変換するシステムである。人間が理解しやすい文字列のドメイン名を入力すると、DNSサーバがその名に対応する数値のアドレスを返すことで、ブラウザなどが正しいサイトに接続できる仕組みになっている。／ 補足(saycon): ドメイン名とIPアドレスを対応付けるシステム
- **ESSID**: 無線LANにおいて、ネットワークを識別するための名前である。
- **FTP**: ファイルをネットワーク上で転送するためのプロトコルである。主に、クライアントとサーバ間でのファイルのアップロードやダウンロードを行う際に使用される。FTPはセキュリティ機能を持たないため、より安全な転送を求める場合はSFTPなどの代替プロトコルが利用される。／ 補足(marke-predict): ネットワーク上でファイル転送を行うためのプロトコル
- **FTTH**: 光ファイバーを使ってインターネット接続を家庭まで直接行う通信サービスで、高速で安定したインターネット接続が可能となる。
- **HDLC**: データ通信用のプロトコルの一つで、データ伝送において信頼性を提供し、エラー検出や訂正を行うために使用される。
- **HTTP**: Web上で情報をやり取りするためのプロトコルである。Webブラウザとサーバ間でデータを送受信する際に使用され、主にWebページやそのコンテンツを取得する役割を果たす。HTTPの動作はリクエストとレスポンスの形式をとる。HTTPにはセキュリティを強化するためのHTTPSというバージョンも存在する。 / Web上でデータを送受信するための通信プロトコルで、Webブラウザとサーバ間の情報やり取りに使用され、テキスト、画像、音声など様々な形式のデータを扱える。／ 補足(saycon): Webブラウザとサーバー間でデータを通信するためのプロトコル
- **http**: Web上で情報をやり取りするためのプロトコルである。Webブラウザとサーバ間でデータを送受信する際に使用され、主にWebページやそのコンテンツを取得する役割を果たす。HTTPの動作はリクエストとレスポンスの形式をとる。HTTPにはセキュリティを強化するためのHTTPSというバージョンも存在する。 / Web上でデータを送受信するための通信プロトコルで、Webブラウザとサーバ間の情報やり取りに使用され、テキスト、画像、音声など様々な形式のデータを扱える。／ 補足(saycon): Webブラウザとサーバー間でデータを通信するためのプロトコル
- **HTTP/2**: Web上でのデータ転送のためのプロトコルの一つである。これは、従来のHTTP/1.1を基にしており、ページの読み込み速度を向上させるために設計された。複数のリクエストを同時に処理できる「フレーミング」と呼ばれる仕組みを持っている。／ 補足(saycon): Webブラウザとサーバー間でデータを通信するためのプロトコル
- **HTTP/3**: Web通信のための最新のプロトコルであり、インターネット上でのデータ転送を効率的に行うために設計されている。従来のHTTP/1.1やHTTP/2と異なり、HTTP/3はQUICというトランスポートプロトコルを基にしている。暗号化通信を標準装備しているため、安全性の向上に寄与している。／ 補足(saycon): Webブラウザとサーバー間でデータを通信するためのプロトコル
- **HTTPS**: インターネット上で安全に情報をやり取りするためのプロトコルで、HTTPにTLSという暗号化技術を組み合わせ、データを第三者から保護する役割を持つ。／ 補足(saycon): HTTPにセキュリティ層を追加し、データ通信を暗号化するプロトコル
- **ICMP**: ネットワーク層で動作するインターネット制御メッセージプロトコルである。主な役割は、ネットワーク内でのエラーメッセージの送信や診断情報の提供である。あるホストがデータを送信する際に、宛先が到達不能である場合、ICMPはその情報を送信元に通知する。「ping」コマンドのようなツールで利用され、ネットワークの接続性をテストする際に非常に便利である。
- **IEEE802.11**: 無線通信に関する標準規格の群であり、主にWi-Fi技術を示す。それぞれのバージョンは異なる通信速度や周波数帯域を持ち、技術の進化と共にデータ転送速度が向上している。802.11aは5GHz帯域を使用し最大54Mbps、802.11nは450Mbps、802.11acや802.11axはさらに高速なデータ転送と同時接続が可能。
- **ifconfig**: ネットワークインターフェースの設定や状態を表示するためのコマンドである。このコマンドは主にUnix系のオペレーティングシステムで使用され、IPアドレスやネットマスク、MACアドレスなどの情報を確認したり、設定を変更したりすることができる。
- **IMAP4**: 電子メールを管理するためのプロトコルであり、メールはサーバ上に保存され、複数のデバイスから同じメールボックスにアクセスでき、メール管理が容易になる。
- **IoTエリアネットワーク**: インターネット接続された様々なデバイスが通信するためのネットワークの一形態で、特にIoTデバイス同士が相互にデータをやり取りするために設計されている。／ 補足(saycon): コンピュータやデバイスを接続して、データを共有できるようにするシステム
- **IP**: ネットワーク上でデータを送受信するためのルールや手順を定めたプロトコルのことである。主に、コンピュータやデバイスが互いに通信する際に使用され、それぞれのデバイスには一意のアドレスが割り当てられる。
- **ip**: ネットワーク上でデータを送受信するためのルールや手順を定めたプロトコルのことである。主に、コンピュータやデバイスが互いに通信する際に使用され、それぞれのデバイスには一意のアドレスが割り当てられる。
- **IPoE**: イーサネット上でIP（インターネットプロトコル）を直接運ぶ技術である。この技術は、特にブロードバンド接続において使用され、データがパケットとしてネットワークを通過する際に、非常に効率的に通信を行うことを可能にする。特に光回線やFTTHサービスにおいてよく用いられ、従来のPPPoEに比べて、接続の安定性や速度が向上することが期待される。
- **IPv4**: インターネット上でデバイスが通信を行うためのプロトコルの一つである。／ 補足(saycon): 32ビットのIPアドレスを使用するインターネットプロトコル
- **IPv6**: インターネット上でデバイスが通信するための新しいアドレッシング方式である。 / インターネットプロトコルの第6版であり、IPアドレスを管理するための主要な技術である。IPv4に代わるもので、より多くのアドレス空間を提供するために設計されている。IPv4が約42億のユニークなアドレスを持つのに対し、IPv6は約340兆兆兆のアドレスをサポートする。／ 補足(saycon): 128ビットのIPアドレスを使用するインターネットプロトコルで、IPv4の後継
- **IP-VPN**: インターネットを利用して仮想的にプライベートネットワークを構築する通信サービスで、暗号化されたデータ通信により、外部からの不正アクセスを防ぐ。
- **IPアドレス**: インターネットやイントラネット上でデバイスを識別するための一意の番号である。この番号は、デバイスが受信するデータを正確に送信するために必要不可欠で、ネットワーク上での位置情報の役割を果たす。このアドレスはIPv4とIPv6の二つの形式が存在し、IPv4は32ビットの数値、IPv6は128ビットの数値形で提供される。／ 補足(saycon): インターネット上でデバイスを識別するための一意なアドレス
- **IP電話**: インターネットを利用して音声通話を行う通信サービスで、データ通信を通じて音声をデジタル信号に変換し、相手に送信する仕組みを持つ。
- **IPパケット**: データ通信において情報を小さな単位に分割して送信する方式のことを指す。 / データ通信において送信するデータを小さな単位に分割したものである。インターネット上では、情報が様々な経路を経て伝送されるため、大きなデータをそのまま送るのではなく、パケットという形にして効率的に扱う必要がある。／ 補足(saycon): データをネットワークで転送するための小さな単位
- **IPヘッダー情報**: データ通信において、送信されるデータの最初に付加される情報のことである。特に、TCP/IPプロトコルのようなネットワーク通信において重要な役割を果たす。ヘッダーには、受信先や送信元のIPアドレス、データの種類、順序番号などが含まれ、これにより正確なデータ転送が行われる。
- **LAN**: 限られた地域内でコンピュータやデバイスを相互接続するためのネットワークである。一般的には、家庭やオフィス内で使用される。／ 補足(saycon): 限られた地域内でコンピュータを接続するネットワーク
- **LPWA**: 低消費電力で広範囲な通信が可能な無線技術で、主にIoTデバイスの接続に利用され、少ないエネルギーで長距離通信を実現することが特徴である。
- **LTE**: 次世代のモバイル通信技術の一つで、高速なデータ通信を実現する規格であり、スマートフォンやタブレットでのインターネット接続速度を大幅に向上させる。
- **MDF**: 通信ネットワークにおいて外部から通じる通信回線を集約する主配線盤である。
- **MIB**: ネットワーク機器やシステムの管理情報を定義するデータベースである。特に、SNMPを使用する際に重要な役割を果たす。管理対象の機器が持つ属性や状態を表すオブジェクトの集合であり、特定のフォーマットで記述されている。
- **MIME**: 電子メールで使用される規格で、テキストだけでなく画像や音声、動画などさまざまなデータタイプをメールで送信できるようにするためのものである。
- **MIMO**: 無線通信において複数のアンテナを同時に使用する技術で、送信側と受信側の両方に複数アンテナを配置することで、データ伝送速度を向上させたり通信の安定性を高める。
- **NAPT**: 複数の内部ネットワークのIPアドレスを一つのグローバルIPアドレスに変換する技術である。
- **NAT**: インターネットに接続されるデバイスのIPアドレスを管理する技術である。
- **netstat**: コンピュータのネットワーク接続状況や統計情報を表示するためのコマンドである。主に、アクティブなTCP/UDP接続、ネットワークインターフェースの状況、ポートの使用状況などを確認できる。
- **NFV**: ネットワーク機能を仮想化する技術である。従来は専用のハードウェアで実行されていたネットワーク機能を、汎用的なサーバ上でソフトウェアとして実行できるようにする。ファイアウォールやロードバランサーといった機能を、仮想マシンとしてデプロイすることで、物理的な機器への依存を減らすことができる。
- **NTP**: コンピュータ同士が正確な時刻を同期するための通信プロトコルである。NTPを使用することで、異なる場所にある複数のコンピュータが、同じ標準時間に基づいて動作することが可能になる。
- **OpenFlow**: ネットワークの構成管理に関するプロトコルの一つである。ネットワーク機器の制御を行うための標準化された方法を提供し、主にソフトウェア・デファインド・ネットワーク（SDN）において利用される。
- **OSI基本参照モデル**: コンピュータネットワークにおける通信プロセスを7つの層に分けて理解するためのフレームワークである。このモデルは、物理層、データリンク層、ネットワーク層、トランスポート層、セッション層、プレゼンテーション層、アプリケーション層から構成されている。
- **ping**: ネットワーク上の通信確認を行うツールである。主に、特定のIPアドレスやホスト名に対して信号を送り、その応答を測定することで、通信の可否や遅延を確認することができる。／ 補足(saycon): 複数のファイルを一つのアーカイブにまとめ、サイズを小さくするプロセス
- **POP3**: 電子メールを受信するためのプロトコルの一つで、メールサーバからパソコンやモバイルデバイスにメールをダウンロードする際に利用され、サーバからメールを削除することが一般的である。
- **POP3S**: 電子メールを受信するためのプロトコルの一つで、メールサーバからパソコンやモバイルデバイスにメールをダウンロードする際に利用され、サーバからメールを削除することが一般的である。
- **PPP**: データリンク層における通信プロトコルの一つである。このプロトコルは、二点間でのデータ通信を効率的に行うための規則や手続きを定めている。主に、インターネット接続やリモート接続などで使用される。データの認証や圧縮、エラー検出を行うための機能も備えており、安全でスムーズな通信を実現する。
- **PPPoE**: イーサネット上でポイントツーポイント接続を確立するためのプロトコルである。このプロトコルは、主にブロードバンド接続に使われ、ユーザーとインターネットサービスプロバイダー（ISP）間でデータ通信を行う際に必要な手段を提供する。PPPoEはユーザー認証を行うことでセキュリティを確保し、個々の接続を管理しやすくする役割を果たす。
- **SDN**: ソフトウェアによってネットワークの制御が行える技術である。従来のネットワークでは、各スイッチやルーターが独立して動作し、手動で設定や管理を行う必要があったが、SDNでは中央のコントローラーが全体を管理するため、効率的にネットワークの設定や変更が可能となる。
- **SMTP**: 電子メールを送信するためのインターネットプロトコルである。このプロトコルは、メールクライアントとメールサーバ間、またはサーバ同士がメールを転送する際に使用される。送信者のメールアドレスや受信者のメールアドレス、件名などの情報が含まれるメッセージを、指定されたサーバに届ける仕組みが整っている。 / 電子メールを送信するためのプロトコルであり、メールクライアントからメールサーバへのメッセージ送信に使用され、ポート番号25で動作し、TLSによる暗号化通信も可能である。／ 補足(marke-predict): 電子メールを送信したりサーバー間で転送するためのプロトコル
- **SNMP**: ネットワーク機器やシステムの状態を管理するためのソフトウェアコンポーネントである。SNMPは、ネットワーク上のデバイスの情報を取得し、監視するための標準プロトコルであり、エージェントはその一部として機能する。／ 補足(marke-predict): ネットワークを運用するための各種機器を管理するためのプロトコル
- **SNMPエージェント**: ネットワーク機器やシステムの状態を管理するためのソフトウェアコンポーネントである。SNMPは、ネットワーク上のデバイスの情報を取得し、監視するための標準プロトコルであり、エージェントはその一部として機能する。／ 補足(marke-predict): ネットワークを運用するための各種機器を管理するためのプロトコル
- **SNMP管理ステーション**: ネットワーク内の機器を監視・管理するためのソフトウェアやハードウェアのことを指す。SNMPプロトコルを利用して、ルーターやスイッチ、サーバなどのネットワーク機器と通信を行う。機器から送られる情報を受け取り、状態や性能を監視するだけでなく、設定変更やトラブルシューティングのための指示を出す機能も持っている。／ 補足(marke-predict): ネットワークを運用するための各種機器を管理するためのプロトコル
- **SOAP**: 異なるシステム間でデータを交換するための通信プロトコルである。主にWebサービスで使用され、XMLという形式でメッセージを記述することが特徴である。これにより、さまざまなプラットフォームやプログラミング言語間での相互運用性が確保される。
- **ss**: ネットワーク運用管理ツールの一つである。システムのパフォーマンスや稼働状況を測定し、評価するための指標を提供する。サーバやネットワーク機器の稼働状況をリアルタイムで監視し、問題が発生した場合には速やかにアラートを通知する機能がある。
- **SSID**: 無線LANにおいて、ネットワークを識別するための名前である。
- **SYN同期方式**: データ通信における同期の方式の一つである。これは、送信側と受信側の間でデータのやり取りを円滑に行うために、タイミングを合わせることを指す。
- **TCP**: インターネット上でデータを安全に送受信するためのプロトコルである。TCPはデータを小さな単位に分け、受信側に順序正しく届けることを保証する機能を持つ。データが正確に届いたかどうかを確認する仕組みがあるため、通信の信頼性が高い。データが欠けた場合には再送信を要求することで、正確な情報伝達を実現している。

- **フレーム**: データを正確に送受信するために、データのまとまり（フレーム）の始まりと終わりを認識する技術である。／ 補足(saycon): ソフトウェア開発において、共通の機能を提供し、効率的な開発を支援するための基盤
- **フレーム同期方式**: データを正確に送受信するために、データのまとまり（フレーム）の始まりと終わりを認識する技術である。
- **プレゼンテーション層**: OSI基本参照モデルにおける第6層であり、データの表示形式を扱う役割を果たす。この層は、受信側と送信側のデータを相互に理解できる形式に変換することを目的とする。
- **フロー制御**: データ通信における操作の一つであり、送信側と受信側のデータ転送の速度を調整する仕組みである。これにより、受信側が処理できるデータ量に応じて、通信が円滑に行える。
- **ブロードキャスト**: 特定のネットワーク内の全ての端末に対して同時にデータを送信する通信方法である。この手法は、ネットワーク層で使われるプロトコルの一つであり、主にLAN内で用いられる。例えば、家庭用ルーターがネットワーク内の全てのコンピュータに同じ情報を送信する場合がある。
- **ブロードキャストアドレス**: 特定のネットワーク内の全ての端末に対して同時にデータを送信する通信方法である。この手法は、ネットワーク層で使われるプロトコルの一つであり、主にLAN内で用いられる。例えば、家庭用ルーターがネットワーク内の全てのコンピュータに同じ情報を送信する場合がある。
- **プロバイダ**: ユーザーがインターネットに接続するためのサービスを提供する業者である。
- **ベーシック手順**: 通信プロトコルにおける基本的な操作や手順を指すもので、特にデータの送受信を行う際の標準的な流れを示すものである。
- **ヘッダー**: データ通信において、送信されるデータの最初に付加される情報のことである。特に、TCP/IPプロトコルのようなネットワーク通信において重要な役割を果たす。ヘッダーには、受信先や送信元のIPアドレス、データの種類、順序番号などが含まれ、これにより正確なデータ転送が行われる。
- **ヘッダー情報**: データ通信において、送信されるデータの最初に付加される情報のことである。特に、TCP/IPプロトコルのようなネットワーク通信において重要な役割を果たす。ヘッダーには、受信先や送信元のIPアドレス、データの種類、順序番号などが含まれ、これにより正確なデータ転送が行われる。
- **ポイントツーポイント接続**: 2つの通信端末が直接接続されているネットワーク構成のことである。この形式は、データ通信が特定の2地点の間でのみ行われるため、通信が効率的かつ安全に行える。
- **ポイントツーポイント方式**: 2つの通信端末が直接接続されているネットワーク構成のことである。この形式は、データ通信が特定の2地点の間でのみ行われるため、通信が効率的かつ安全に行える。
- **ポート番号**: ネットワークにおける通信の接続先を特定するための識別番号である。これは、特定のアプリケーションやサービスが利用するデータの経路を示すもので、通常は0から65535までの範囲で指定される。TCPやUDPは、それぞれ特定のポート番号を用いて通信を行う。／ 補足(marke-predict): TCPまたはUDPを使ったネットワークにおいてどのアプリケーションの通信データ量を識別する番号

- **マルチリンク手順**: 複数の通信リンクを同時に利用してデータを効率的に伝送するための手続きである。この技術は、データ通信の速度を向上させたり、通信の安定性を高めるために用いられる。

- **ローミング**: 携帯電話などのモバイル端末が、自国以外の地域で通信サービスを利用するための仕組みで、海外の通信事業者のネットワークを借りて利用できる。
