- **MTBF**: fe-siken: 機器やシステムの信頼性を評価する指標の一つである。具体的には、故障と故障の間に稼働している平均時間を示すもので、通常は時間単位で表される
- **MTTR**: fe-siken: システムや機器が故障した際、修理に要する平均的な時間のことである。信頼性工学において非常に重要な指標であり、トラブル発生時の対応能力を示す
- **RAID**: fe-siken（「RAID0」等、個別レベルの説明のみ。総称としての一般説明はなし） ／ 補足（marke-predict）: 高速性や耐障害性を高める目的で複数の外部記憶装置を1台の装置として管理する技術
- **RAID0**: fe-siken: 複数のストレージデバイスを組み合わせて、一つの論理ドライブとして扱う方法の一つである
- **RAID1**: fe-siken: データの冗長性を確保するためのストレージ技術の一つである
- **RAID10**: fe-siken: データの冗長性とパフォーマンスを両立させるためのストレージ構成である
- **RAID2〜4**: fe-siken（個別に3項目あり）: RAID2＝独立した複数のディスクを用いてデータを冗長化し、高い信頼性を持つストレージ構成の一つ／RAID3＝冗長性を持ったデータストレージ技術の一つであり、データを複数のディスクに分散して保存する方式／RAID4＝ディスクアレイの一種であり、データの冗長性を確保しながらストレージ性能を向上させる技術
- **RAID5**: fe-siken: データの保護とパフォーマンス向上を目的としたストレージ技術の一つである
- **RAID6**: fe-siken: 独立した複数のハードディスクにデータを分散して保存し、同時にパリティ情報を2箇所に保持するストレージ技術である
- **RASIS**: fe-siken: システムやサービスの信頼性と運用の質を評価するための指標である。信頼性（Reliability）、可用性（Availability）、保守性（Serviceability）、完全性（Integrity）、セキュリティ（Security）の5要素からなる
- **SAN**: fe-siken（「SAN（ストレージエリアネットワーク）」表記）: ストレージエリアネットワークの略称で、主にデータストレージを効率的に扱うためのネットワーク技術である
- **VDI**: fe-siken（「VDI（仮想デスクトップインフラストラクチャ）」表記）: デスクトップ仮想化の一形態であり、ユーザーのデスクトップ環境を中央のサーバ上で仮想的に管理し、提供する技術である
- **Webシステム**: fe-siken: インターネットを利用して提供されるアプリケーションやサービスのことを指す
- **アクティブ-アクティブ構成**: fe-siken: 複数のシステムやコンポーネントが同時に稼働し、負荷を分散させることで、全体の信頼性と可用性を向上させる設計方式である
