# グループF（ビジネスインダストリ・企業活動・法務）低確信度リスト

担当3分野のsummary作成にあたり、情報源が薄く一般知識のみで書いた語のうち、特に確信度が低いものを列挙する。それ以外の「情報源なし」語は、fe-siken/marke-predict/e-wordsのいずれかで裏付けが取れる一般常識の範囲として通常の確信度で作成した。

## ビジネスインダストリ

- **CII標準**: fe-siken・e-wordsともに掲載なし。「日本の企業間電子商取引で使われる、取引手順の標準規約」という要旨で書いたが、正式名称・策定主体（CII＝Center for the Informatization of Industry）の細部までは確認できていない。
- **アクティビティトレーサー**: 「アクティビティトラッカ」と明確に区別できる情報源が見つからず、同一概念（活動量計）として同趣旨のsummaryを書いた。両者が実際に異なる概念を指す用語である可能性が残る。
- **機械電子制御**: fe-siken・e-wordsともに掲載なし。「機械の動作を電子回路やコンピュータで制御する技術」という一般的なメカトロニクス概念として書いたが、試験用語としての厳密な定義は確認できていない。

## 企業活動

- **MBO**: e-wordsの掲載はManagement Buyout（経営陣による自社株買収）の意味のみだが、企業活動の文脈（経営・組織論）ではManagement by Objectives（目標管理制度）を指す可能性もある。どちらの意味かfe-siken側の文脈だけでは確定できず、Management Buyoutの意味で書いた。

## 法務

- **PDS**: fe-siken・e-wordsともに掲載なく、略語のため意味の同定が特に困難（`_flags.md`でも指摘あり）。法務分野・個人情報関連の並びから「パーソナルデータストア（Personal Data Store）」と推測して書いたが、他の略語（Public Domain Software等）を指す可能性も残る。
- **知的財産適用管理**: fe-siken・e-wordsともに掲載なく、`_flags.md`でも「一般的な用語辞典にも見当たらず、terms.json側の表記自体が正確か要確認」と指摘されている語。「知的財産権の活用や、他者の権利侵害を防ぐための社内管理活動」という推測に基づく要旨で書いた。
