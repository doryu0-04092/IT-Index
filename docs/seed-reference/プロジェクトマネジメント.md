# プロジェクトマネジメント — 参考情報（fe-siken.com主軸）

出典: fe-siken.com カテゴリ14「プロジェクトマネジメント」(14-1〜14-11)。補足はmarke-predict（マネジメント系/プロジェクトマネジメント）。

- **AC**: 実コストとして14-7に掲載。「実際に発生した費用のことを指す」（Actual Costの日本語名として掲載）
- **BAC**: 情報源なし → e-wordsで確認: 「BAC（Budget At Completion）とは、プロジェクト完了時点での予算総額（完成時総予算）を指す」(e-words.jp「EVM」)
- **COCOMO II**: 「ソフトウェア開発プロジェクトのコストや工数を予測するためのモデルである」（COCOMOⅡ表記、14-7）
- **CPI**: 情報源なし → e-wordsで確認: 「コスト効率指数（CPI）は、出来高（EV）と実コスト（AC）の比（EV/AC）。1を超えれば予算内、1を下回れば予算超過を示す」(e-words.jp「コスト効率指数（CPI）」)
- **CPM**: 「プロジェクト管理の手法の一つであり、タスクの最長経路を特定することで、プロジェクトの最短完了時間を計算するために使用される」(14-6)
- **EAC**: 情報源なし → e-wordsで確認: 「EAC（Estimate At Completion）は、プロジェクト完了時点の総コストの見積り。AC＋(BAC－EV)/CPIの式などで算出される」(e-words.jp「EVM」)
- **EV**: 情報源なし → e-wordsで確認: 「EV（Earned Value、出来高）は、ある時点までに完了した作業の予算コストの合計」(e-words.jp「EVM」)
- **EVM**: 「プロジェクト管理における進捗を評価する手法である」(14-6/14-7)
- **FF**: 情報源なし → e-wordsで確認: 「FF（Finish-to-Finish）は、プレシデンスダイアグラム法における依存関係の一種。「作業Aが終わったら作業Bも終了する」という関係」(e-words.jp「プレシデンスダイアグラム法（PDM）」)
- **FP値**: 情報源なし（関連: ファンクションポイント法は掲載あり）
- **FP法**: ファンクションポイント法として14-7に掲載
- **FS**: 情報源なし → e-wordsで確認: 「FS（Finish-to-Start）は、プレシデンスダイアグラム法における依存関係の一種。「作業Aが終わったら作業Bを開始する」という関係」(e-words.jp「プレシデンスダイアグラム法（PDM）」)
- **ISO 21500**: 関連: JIS Q 21500として14-1に掲載（ISO 21500の国内規格版）
- **JIS Q 21500**: 「プロジェクトマネジメントに関する日本の規格である」(14-1)
- **LOC法**: 「ソフトウェアの規模や複雑さを測定する方法の一つである。この方法は、ソースコードの行数を基にして、開発の進捗状況や労力を評価するために使われる」(14-7)
- **P2M**: 情報源なし（e-wordsにも該当ページなし。要本人確認。日本発のプログラム＆プロジェクトマネジメント標準で、PMBOKとは別の日本独自規格である点に注意）
- **PDM**: 情報源なし（→ プレシデンスダイアグラム法と同義（略語）。下記「プレシデンスダイアグラム法」の項目を参照）
- **PERT**: 「プロジェクトの計画と管理において用いられる手法の一つである」(14-6)。補足marke-predict「アローダイアグラム（PERT）: プロジェクトの作業手順を表したもので計画の進捗管理を行う手法」
- **PM**: プロジェクトマネジメントの略として14-1に掲載
- **PMBOK**: 「プロジェクトマネジメントのための知識体系のことである」(14-1)
- **PMO**: 「プロジェクトを効率的に管理するための組織体制である」(14-1)
- **PV**: 情報源なし → e-wordsで確認: 「PV（Planned Value、計画価値）は、ある時点までに完了予定の作業の計画予算コスト」(e-words.jp「EVM」)
- **SF**: 情報源なし → e-wordsで確認: 「SF（Start-to-Finish）は、プレシデンスダイアグラム法における依存関係の一種。「作業Aが開始されたら作業Bを終了する」という関係」(e-words.jp「プレシデンスダイアグラム法（PDM）」)
- **SPI**: 情報源なし → e-wordsで確認: 「スケジュール効率指数（SPI）は、出来高（EV）と計画価値（PV）の比（EV/PV）。1を超えれば計画より進んでおり、1を下回れば遅延を示す」(e-words.jp「スケジュール効率指数（SPI）」。注: SPIはSerial Peripheral Interfaceの略でもあり紛らわしい）
- **SS**: 情報源なし → e-wordsで確認: 「SS（Start-to-Start）は、プレシデンスダイアグラム法における依存関係の一種。「作業Aが始まったら作業Bも開始する」という関係」(e-words.jp「プレシデンスダイアグラム法（PDM）」)
- **SV**: 情報源なし → e-wordsで確認: 「SV（スケジュール差異）は、ある時点のEV（出来高）とPV（計画価値）の差。マイナスであれば計画より遅延していることを示す」(e-words.jp「EVM」)
