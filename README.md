# IT-Index

IT用語をかな・カタカナ・英字のどれでも検索できる、個人用のIT用語辞書アプリです。**PCはブラウザ、AndroidはAPKアプリ**として使えます。用語・ノート・履歴はすべて端末内のIndexedDBに保存され、辞書としての機能は端末内だけで完結します（AIチャットと端末間同期だけは公式サーバーを経由します）。

## できること

- **検索**: 内蔵の3510語（IPAシラバスをもとにした24分類）を、読み・カタカナ・英字のどれで入力しても検索できます
- **AIチャット**: 用語について質問すると、AIが調べた内容を「理解のための補足」として蓄積します（無料のアカウント登録とログインが必要です。ご自身のAPIキー（OpenAI / Anthropic）を登録すれば無料で使えます）
- **端末間同期**: 単語帳・ノート・履歴を、PCとAndroidで同じ状態に揃えられます（公式サーバー経由のため、同じネットワークにいる必要はありません。プレミアム（月額 ¥300）の機能です）
- **ライト/ダークモード切り替え**

## インストール

個人利用向けの配布です（商業目的の配布は予定していません）。

### PC版

インストールは不要です。ブラウザで **https://it-index.doryu.workers.dev** を開いてください（Chrome/Edgeを想定しています）。

### Android版

1. [**it-index-android-0.3.0.apk をダウンロード**](https://github.com/doryu0-04092/IT-Index/releases/download/v2-android-0.3.0/it-index-android-0.3.0.apk)（[Releases](../../releases) にも同じファイルがあります）をスマートフォンで開きます（ブラウザから直接ダウンロードするか、PCでダウンロードしてから任意の方法で転送しても構いません）
2. ファイルを開くと **「提供元不明のアプリ」** の確認が出ます。Google Play を経由しないアプリはすべてこの扱いになります。表示された設定画面で、ダウンロードに使ったアプリ（Chrome やファイルマネージャー）に「この提供元のアプリを許可」を有効にしてください
3. 戻ってインストールします

> **APKはデバッグ署名のビルドです。** Google Play で配布するための署名は行っていません。動作の確認には問題ありませんが、Play ストア経由ではないため自動更新はされません。新しい版は都度ダウンロードして上書きインストールしてください。

手元でビルドしたい場合は、下記「配布ファイルを作る」を参照してください。

## 端末間同期（PC ⇔ Android）

公式サーバーを中継して、単語帳・ノート・履歴を複数の端末で同じ状態に揃えられます。**同じネットワークにいる必要はありません。**

1. 「同期」タブでアカウントを作成し（メールアドレスとパスワード）、ログインします
2. 「設定」タブからプレミアム（月額 ¥300・毎月自動更新）を購入し、ライセンスを有効にします
3. 各端末で同期を実行すると、差分が送受信されて統合されます

同じ用語のノートを両方の端末で別々に編集した場合は**競合**として記録され、どちらを採用するか選べます（選び直しはPC側で行います）。

### 自分のサーバーで動かす場合

サーバーを自分のCloudflareアカウントに立てると（セルフホスト）、同期とAIの中継が**ライセンス不要**で使えます（運用と費用は自己負担になります）。手順は `docs/v2/deploy.md` を参照してください。アプリの「設定」タブの「接続先サーバー」に自分のサーバーのURLを入れると、接続先が切り替わります。

### 安全性について

端末⇔サーバーの通信はHTTPSで、認証済みのアカウントだけが自分のデータを読み書きできます。AIチャットの質問文はサーバーを経由してAI事業者へ渡りますが、**サーバーには保存されません**（保存されるのは利用回数のみです）。

同期でサーバーに預けるデータは、**端末内で暗号化してから送られます**。鍵は端末が持ち、サーバーには渡りません。そのためサーバー側では中身を読めません。

初めて別の端末で同期するときは、**鍵の受け渡し**が必要です（「同期」タブの「同期の鍵」）。

- **QRで渡す（基本の方法）**: 片方に表示したQRを、もう片方のカメラで読み取ります。鍵がサーバーを通らないので最も安全です。ただし**QRの画面を他の人に見せないでください**（鍵そのものが写っています）
- **8桁の数字コード**: カメラが使えないときの代替で、「QRが使えない場合」を開くと出てきます。この方法では包んだ鍵が5分だけサーバーに置かれるため、QRで渡せる場合はQRをお使いください

すべての端末で鍵が分からなくなった場合は、「鍵を作り直す」でやり直せます。**端末内のデータは消えません**が、サーバー上に溜まっていた差分は読めなくなるため削除され、各端末で同期をやり直すことになります。

## 開発環境で動かす

**配布しているのは `v2/` のアプリです。** リポジトリ直下にはv1（Electron版・LAN直結連携）のコードも残っていますが、配布物とは別のアプリです。

```sh
cd v2
npm install
npm run dev -w client   # ブラウザで開発（http://localhost:5173）
```

ブラウザで開く場合はChrome/Edgeを想定しています。

### 配布ファイルを作る

```sh
cd v2/client
npm run build:android   # Webをビルドして android/ へ反映
npx cap open android    # Android StudioでAPKを生成（Build → Build Bundle(s) / APK(s) → Build APK(s)）
```

Android版のビルドには JDK 17以降 と Android SDK が必要です。サーバーのデプロイを含む詳しい手順は `docs/v2/deploy.md` にあります。
