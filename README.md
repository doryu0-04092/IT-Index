# IT-Index

IT用語をかな・カタカナ・英字のどれでも検索できる、個人用のIT用語辞書アプリです。**PC（Windows）とAndroidの2つのアプリ**があり、料金のかかる外部サーバーは使いません（データはすべて端末内のIndexedDBに保存されます）。

## できること

- **検索**: 内蔵の3510語（IPAシラバス24分類）を、読み・カタカナ・英字のどれで入力しても検索できます
- **AIチャット**: 用語について質問すると、AIが調べた内容を「理解のための補足」として蓄積します（Anthropic Claude / OpenAI / Google Geminiのいずれかの、ご自身のAPIキーが必要です）
- **端末間の連携**: PCとAndroidを**同じWi-FiにつないでQRコードを読むだけ**で、蓄積した用語の説明を両方の端末で同じ状態に揃えられます。アカウント登録もインターネット接続も不要です
- **ライト/ダークモード切り替え**

## インストール

個人利用向けの配布です（商業目的の配布は予定していません）。

### PC版

インストールは不要です。ブラウザで **https://it-index.doryu.workers.dev** を開いてください（Chrome/Edgeを想定しています）。

### Android版

1. [**it-index-android-0.3.0.apk をダウンロード**](https://github.com/doryu0-04092/IT-Index/releases/download/v2-android-0.3.0/it-index-android-0.3.0.apk)（[Releases](../../releases) にも同じファイルがあります）をスマートフォンで開きます（ブラウザから直接ダウンロードするか、PCでダウンロードしてから任意の方法で転送しても構いません）
2. ファイルを開くと **「提供元不明のアプリ」** の確認が出ます。Google Play を経由しないアプリはすべてこの扱いになります。表示された設定画面で、ダウンロードに使ったアプリ（Chrome やファイルマネージャー）に「この提供元のアプリを許可」を有効にしてください
3. 戻ってインストールします

> **APKはデバッグ署名のビルドです。** Google Play で配布するための署名は行っていません。動作の確認には問題ありませんが、Play ストア経由ではないため自動更新はされません。新しい版は都度ダウンロードして上書きインストールしてください。

手元でビルドしたい場合は、下記「配布ファイルを作る」を参照してください。

## 端末間の連携（PC ⇔ Android）

**両方の端末が同じWi-Fiにつながっていれば**、1往復で両方のデータが同じ状態になります。中継サーバーもアカウントも使いません。

1. どちらか片方で「連携」を開き、**「QRを表示する」** を選びます（Android版はメニュー ☰ の中にあります）
2. もう片方で「連携」→ **「カメラで読み取る」** を選び、表示されたQRを読みます
3. 自動的に双方のデータが送り合われ、統合されます

**どちらがQRを表示しても結果は同じ**です。PCにカメラが無い場合は、PC側を「QRを表示する」、スマホ側を「カメラで読み取る」にしてください（スマホには必ずカメラがあるため、この組み合わせは常に使えます）。

### うまくいかないとき

- **同じWi-Fiにいるか確認してください。** 片方がモバイル回線だと繋がりません
- ゲストWi-Fiや、公共のWi-Fiでは端末どうしの通信が遮断されていることがあります
- それでも駄目な場合は **「ファイルでやり取りする」** を使ってください。ネットワークを一切使わず、書き出したファイルをメールやUSBなど任意の方法で移して読み込ませる方式です

### 安全性について

QRコードには接続先のアドレスと**その場限りの暗号鍵**だけが入っています。やり取りするデータはこの鍵で暗号化されるため、同じWi-Fi上の第三者に中身を読まれることはありません。接続先は自宅LANなどのプライベートアドレスに限定しており、外部のサーバーへ送信されることはありません。

## 開発環境で動かす

```sh
npm install
npm run dev          # ブラウザで開発（http://localhost:5173）
npm run dev:electron # PC版アプリとして起動
```

ブラウザで開く場合はChrome/Edgeを想定しています。

### 配布ファイルを作る

```sh
npm run build:electron   # PC版インストーラ → release/ に出力
npm run build:android    # Webをビルドして android/ へ反映
cd android && ./gradlew.bat assembleDebug
                         # APK → android/app/build/outputs/apk/debug/app-debug.apk
```

Android版のビルドには JDK 17以降 と Android SDK が必要です。
